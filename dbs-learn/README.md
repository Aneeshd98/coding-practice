# Subthalamic Lab

An interactive teaching course on **deep brain stimulation (DBS) sensing**. Learners work with a live, simulated recording of local field potentials (LFPs) from two four-contact leads in the subthalamic nucleus (STN), the way sensing-enabled DBS systems record them, alongside a 3D brain in which the STN glows with the patient's live beta activity.

> Teaching simulation only. It does not model any specific device and must not be used for clinical decisions or to choose stimulation settings.

## Course (first version)

| Module | Lessons | Graded practical |
|---|---|---|
| 1. Leads and sensing | Where the lead sits · Why record between contacts · Find the beta contacts | Identify the adjacent pair with the most beta, measured from the last 8 s of the recording |
| 2. Beta and medication | Read an LFP spectrum · Levodopa and beta | Capture settled OFF and ON windows and report the beta power ratio |
| 3. Bursts and movement | Beta comes in bursts · Movement and the beta rebound | Report the ON mean burst duration using a threshold fixed from the OFF baseline |
| 4. Stimulation and artifacts | The stimulation artifact · Sandwich sensing · Stimulation suppresses beta | Measure the aliased 130 Hz artifact (≈120 Hz at 250 Hz sampling) |

Every lesson has a guide, a hands-on experiment and a checkpoint. Practicals are graded from the learner's actual recorded samples, so they cannot be passed by guessing, and they reject windows recorded in the wrong state (for example, an ON capture taken before the medication effect settled).

## Run it

Requires Node.js 22 or newer.

```sh
npm install
npm run dev          # http://127.0.0.1:5173
npm test             # model, DSP and grading tests
npm run build        # type-check and production build into dist/
npm run test:browser # Playwright end-to-end tests (set CHROME_PATH to use a preinstalled Chromium)
```

## How it works

| Part | Files | What it does |
|---|---|---|
| Simulator | `src/sim/model.ts`, `src/sim/worker.ts` | Seeded generator in a Web Worker at 250 Hz. Each frame holds 8 contact voltages (vs. the implant case), a matching artifact-free neural copy, and witness lanes (ECG, stimulation amplitude, true burst state). |
| Physiology | `model.ts` | 1/f-like background, bursty beta whose rate, duration and size depend on medication, movement and stimulation; a hidden per-patient beta frequency and generator edge; contralateral movement desynchronization and post-movement rebound; ECG pickup through the chest-mounted case; a 130 Hz stimulation artifact that aliases to 120 Hz and saturates nearby channels. |
| Signal processing | `src/dsp/` | Ring buffer with state history, bipolar/monopolar montages with ±400 µV differential saturation, Welch spectra, zero-phase band-pass, analytic envelope, burst detection, cue-locked power averaging. |
| Course | `src/course/` | Lesson content with references, and practical graders that measure the recording. |
| 3D brain | `src/three/`, `src/ui/BrainPanel.tsx` | Three.js scene: a glass (or solid) brain from adapted atlas surfaces, schematic deep nuclei at textbook MNI positions, two four-contact leads on a 60°/15° frontal trajectory, an STN whose glow follows the live beta envelope, a pulsing activation volume around the stimulating contact, and the hidden beta edge placed exactly where the signal model puts it. Overview, coronal, sagittal and target views; 2D fallback without WebGL. |
| Anatomy pipeline | `scripts/prepare_anatomy.py` | Splits and regroups the CC BY-SA atlas surfaces and converts them to millimetres. See `public/anatomy/ATTRIBUTION.txt`. |
| UI | `src/ui/`, `src/app/lab.tsx` | React app: live trace canvas, spectrum, burst, movement and stimulation tools, course map and free lab. Light and dark themes. |

## Known simplifications

- Beta is generated by an envelope-modulated oscillator, not a network model. Its edge is a smooth step along the lead, which makes the "pair straddling the edge" logic clean. Real anatomy is messier.
- The levodopa effect takes about 10 seconds here instead of tens of minutes.
- The stimulation artifact is modelled after anti-alias filtering (fundamental plus a weak harmonic). Real artifacts depend on the device, pulse shape and electrode impedance. Saturation is modelled, so a clipped channel produces aliased harmonics, including a spurious 20 Hz peak.
- The deep nuclei are rounded ellipsoids and tubes at approximate positions, not an atlas. The activation volume is an illustrative sphere, not a field model.
- No real recordings are bundled yet. Open STN-LFP datasets exist, but their redistribution licences need checking first.
- The physiology should be reviewed by a DBS clinician or electrophysiologist before learners rely on it.
